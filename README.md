# 📊 Excel Data Analyst Dashboard

* Excel Formulas

* Analytical Skills

## 📈 Key Features

* Interactive dashboard
* KPI analysis
* Pivot Table-based analysis
* Charts and visualizations
* Trend and performance analysis
* Data-driven business insights

To analyze raw data and create an easy-to-understand dashboard that helps identify important trends, patterns, and performance metrics for better decision-making.
